Case Study — AI Marketplace Platform
Overview

An AI-powered marketplace concept that helps sellers list items faster — the model looks at a product listing, detects its condition, suggests the right category, and recommends a fair price using Machine Learning, instead of leaving all of that guesswork to the seller.

My Role & Contribution

Built the front-end interface with HTML, CSS and JavaScript, and the Python/Flask backend that connects the listing form to the Machine Learning logic behind condition detection, category suggestion, and price recommendation.

Architecture Summary
  • HTML/CSS/JavaScript front-end for browsing and listing products
  • Python + Flask backend serving the Machine Learning predictions
  • Modules for condition detection, category suggestion, and price recommendation
Why It's Interesting

It brings together the two sides I'm most drawn to — practical web development and applied Machine Learning — inside one working product rather than as two separate exercises.

Status

A personal project I'm actively building and refining as I go deeper into AI and Machine Learning.
